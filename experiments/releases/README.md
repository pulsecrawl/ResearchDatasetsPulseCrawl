# Reviewed evidence releases

The current reviewed live evidence is the
[`thesis-live-universe-v1.0.0`](thesis-live-universe-v1.0.0/) release. It
contains five categories, 75 websites, 300 successful site executions, and
matching reviewer-readable CSV and queryable Parquet files.

Controlled experiment evidence remains under
[`experiments/controlled/`](../controlled/). Every controlled run includes a
README, resolved configuration, direct measurements, and checksums; runs that
produce datasets also include CSV and Parquet companions.

Releases never contain third-party response bodies, local SQLite state,
process identifiers, workstation paths, or credentials.
