# Readable evidence

Every table is published as matching CSV and Parquet files. `records` contains target records, `pages` contains the complete URL-level crawl trace, `execution-summary` and `site-summary` explain the run totals, and `suppressed-page-samples` shows navigation or ignored examples. The `records-preview.csv` and `pages-preview.csv` files contain the first 200 rows for direct browser inspection; the unsuffixed files are the complete tables.
